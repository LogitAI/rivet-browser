# Rivet Browser

[![License: Apache-2.0](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](../../LICENSE)

[English](../../README.md) · **한국어**

**브라우저는 유지하고, 프레임은 바꾼다.**

Rivet Browser는 사용자가 설치한 Chromium 계열 브라우저용 Windows 우선 오픈 소스 브라우저
프레임입니다. 엔진, 프로필, 로그인, 확장 프로그램, 미디어 스택, 업데이트는 사용자가 고른
브라우저가 계속 맡습니다. Rivet은 프레임, 작업 공간, 에이전트 제어 표면을 제공합니다.

Rivet은 Chromium 포크가 아니며 웹뷰 브라우저도 아닙니다.

## 상태

**초기 구현 단계입니다.** Rust 작업 공간에는 실험적인 `rivet session start` 명령, 생성된 로컬 제어
프로토콜, Windows 런타임 주입 부트스트랩이 있습니다. 사용자가 명시한 Chromium 실행 파일을 보이는
모드나 숨김 모드로 시작할 수 있습니다. 직접 네이티브 프레임, 브라우저 제어 명령, Ember 통합, 설치기는
아직 완성되지 않았습니다.

## Rivet이 하려는 일

- Windows에서 사용자가 설치한 Chromium 계열 브라우저를 시작하고 직접 통합합니다.
- 실제 브라우저 프로세스와 브라우저가 맡은 기능은 유지하면서, 보이는 브라우저 프레임을 Rivet의
  네이티브 프레임으로 바꿉니다.
- 사람과 에이전트에 같은 브라우저 제어 표면을 CLI로 제공합니다.
- 시각 확인과 UI 자동화에는 보이는 표시를, 브라우저 처리만 필요할 때는 숨김 표시를 호출자가 고르게
  합니다.
- 사용자가 등록한 데스크톱 클라이언트 사이를 옮겨도 Ember가 Rivet 설정과 논리 작업 공간을 조율하게
  합니다.

숨김 표시는 페이지 렌더러가 없다는 뜻이 아닙니다. JavaScript, 레이아웃, 탐색은 브라우저에서 계속
실행합니다. 호출자가 요청하지 않으면 Rivet이 보이는 합성 표면을 만들거나 프레임을 캡처하지 않는다는
뜻입니다.

## 저장소

- `rivet/`: 모든 Rivet 코드와 패키징 입력입니다. 구현 언어는 Rust입니다.
- `docs/locales/`: 이 README의 번역입니다.
- `scripts/tests/`: 저장소 검사입니다.

작업은 `develop`에서 합니다. 공개는 `develop`에서 `release`, `main`으로 단방향으로 진행하며,
풀 리퀘스트를 거칩니다. 내부 계획 문서는 `develop`에만 남습니다.
